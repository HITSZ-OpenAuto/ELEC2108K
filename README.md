## 学习建议
<!-- TOML-SECTION: title="学习建议" -->

<!-- TOML-ITEM: id="item-学习建议-1" -->

- 少数由韩方授课、且只有理论课而没有实验课的课程之一。
- 这门课像是高等数学和线性代数的结合与延伸，整门课几乎都围绕解微分方程展开。前两章与高数中的微分方程部分几乎完全一样；第三章开始讲高阶微分方程的解法，思路与前两章大同小异。第四章起引入线性代数和空间解析几何的知识，借助矩阵和特征值来解微分方程。第五章计算量较大，主要讲 Frobenius Method 和两类 Bessel Functions 在解微分方程中的应用。第六章讲用拉普拉斯变换解微分方程，并联系了一些电路方面的知识。

## 考核方式
<!-- TOML-SECTION: title="考核方式" -->

<!-- TOML-ITEM: id="item-考核方式-1" -->

- 课后作业: 20%
  - 包含前四章一次作业，五六章一次作业，还有最后几节课课后的小测。
- 期中考试: 30%
  - 会占用合适时间某节课程表上的工程数学课在正常上课教室进行期中考试，考前会提前通知。
  - 共 3 道题，总计 60 分钟，前三章每章出一道题。
  - 这 3 道题不会印在同一张试卷上，而是每张纸上印有一道题，严格按照每 20 分钟收发一次试卷，无法自由分配答题时间，所以也几乎无法提前交卷离开。
- 期末考试: 50%
  - 该门课程结课时间较早，25 级 11 月 23 日就进行了期末考试。
  - 共 5 道题，老师在考前对每道题的考察内容都进行了较详细的说明，25 级题目安排如下（转述老师通知）：

  3. This course covers methods for solving differential equations, with a primary focus on finding solutions in the time domain (as presented in Chapters 1 through 3). Consequently, it is not possible to exclude Chapters 1–3 from the scope of the examination. Nevertheless, while content regarding time-domain solution methods has been largely omitted, only Problem 4 does include a task requiring the derivation of a solution in the time domain—specifically, the simplest type of such a solution.
